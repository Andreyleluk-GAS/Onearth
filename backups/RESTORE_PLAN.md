## 2. Сценарии восстановления

### Сценарий 1: Быстрый откат в существующей рабочей директории (Quick Rollback)
Используется, если текущий рабочий каталог `19_TR-project` сохранен, но требуется вернуться к состоянию до выполнения Задания 2.

```bash
# 1. Проверить статус репозитория
git status

# 2. Сбросить все незакоммиченные изменения и откатить ветку к коммиту 3bc22a7
git reset --hard 3bc22a7

# 3. Удалить неотслеживаемые новые файлы (если появились)
git clean -fd

# 4. Пересобрать проект и проверить
npm run build:full
```

Если изменения уже были отправлены в удаленный репозиторий GitHub (`origin/main`) и их нужно отменить:
```bash
# Вариант А: безопасный revert коммита
git revert HEAD --no-edit
git push origin main

# Вариант Б: принудительный возврат к базовому коммиту (требует прав force push)
git reset --hard 3bc22a7
git push origin main --force
```

### Сценарий 2: Развертывание из Git Bundle в новую чистую папку (Offline Full Restore)
Используется при повреждении директории или необходимости развернуть точную копию в новой папке без интернета:

```bash
# 1. Перейдите в желаемую директорию
cd D:\_PROMTING\1_SITE

# 2. Клонируйте репозиторий напрямую из бандла
git clone "D:\_PROMTING\1_SITE\19_TR-project\backups\onearth_repo_backup_commit_3bc22a7.bundle" Onearth_Restored

# 3. Перейдите в созданную папку
cd Onearth_Restored

# 4. Подключите удаленный репозиторий GitHub
git remote set-url origin https://github.com/Andreyleluk-GAS/Onearth.git

# 5. Установите зависимости и запустите сборку
npm install
npm run build:full
```

---

### Сценарий 3: Восстановление из ZIP архива
Используется на машинах без установленного Git или при потребности в чистых файлах:

1. Распаковать `onearth_source_backup_commit_3bc22a7.zip` в целевую папку (например, `D:\_PROMTING\1_SITE\Onearth_Zip_Restored`).
2. Открыть терминал в распакованной папке.
3. Выполнить:
   ```bash
   npm install
   npm run build:full
   npm run preview
   ```
