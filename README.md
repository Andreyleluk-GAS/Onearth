# Hubei Onearth Trading Company Limited — Трансформаторное оборудование из Китая

B2B цифровая платформа и каталог силовых трансформаторов (10, 20 и 35 кВ, мощности 630–2500 кВА) для российских предприятий.

* **Компания:** Hubei Onearth Trading Company Limited
* **Базис поставки:** FCA Маньчжурия (Инкотермс 2020)
* **Контакты:** +7 (343) 123-45-67, mail@mail.ru

## Линейка оборудования (7 категорий)
1. Сухие трансформаторы с литой изоляцией на 10 кВ (ПБВ ±2х2,5%, 630–2500 кВА, Uк = 6% и 8%)
2. Сухие трансформаторы 10 кВ с пониженными потерями (энергоэффективные, сниженные потери P₀)
3. Сухие трансформаторы с литой изоляцией на 20 кВ (для кабельных сетей 20 кВ)
4. Сухие трансформаторы с литой изоляцией на 35 кВ
5. Сухие трансформаторы 35 кВ с пониженными потерями
6. Сухие трансформаторы с воздушно-барьерной изоляцией, 10 кВ (класс нагревостойкости H, Nomex)
7. Масляные трансформаторы на 35 кВ (герметичные, ПБВ ±2х2,5%, Uк = 6,5%)

## Стек технологий
* **Фреймворк:** React 18 + TypeScript + Vite
* **Стилизация:** Tailwind CSS
* **Иконки:** Lucide React
* **Инжиниринг:** Интерактивные SVG-графики технологических потерь (P₀ / Pкз), калькулятор годовой экономии электроэнергии и ROI
* **Сборка и SSG:** Статическая генерация страниц (SSG-снапшоты), sitemap.xml, robots.txt, семантический экспорт
* **Деплой:** GitHub Actions CI/CD на GitHub Pages

## Локальный запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального dev-сервера (http://localhost:3000/Onearth/)
npm run dev

# Полная сборка с SSG и SEO-генерацией
npm run build:full
```

## Деплой на GitHub Pages
Проект настроен на автоматическую сборку и публикацию в GitHub Pages при каждом пуше в ветку `main` через GitHub Actions (`.github/workflows/deploy.yml`).
