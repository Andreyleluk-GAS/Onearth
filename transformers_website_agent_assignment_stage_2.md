# ТЗ для агента: SEO-семантика, Product Matrix, IA, каталог и лидогенерация

**Проект:** B2B-сайт силовых трансформаторов в РФ  
**Дата:** 2026-11-05  
**Главная цель:** квалифицированные B2B-лиды, а не просто трафик.

## 1. Контекст

Продукт:
- 6/10 кВ, 630–3150 кВА;
- 35 кВ, 4000–31500 кВА;
- масляные и сухие трансформаторы;
- стандартная российская номенклатура;
- разработка/изготовление нестандартных исполнений по ТЗ.

Позиционирование: **«Трансформатор под задачу»** — каталог + инженерный подбор + ТЗ + нестандарт + аналоги + документация.

Три основных сценария:
1. **Знаю модель** → каталог → карточка → документы → КП.
2. **Знаю параметры** → подбор → подходящие модели → КП.
3. **Есть ТЗ** → загрузка → инженер → техническое решение → КП.

Дополнительный: **нужен аналог** → параметры/фото шильдика → проверка → КП.

# 7. SEO-фильтры

Индексируемая комбинация фильтров допускается только если:
1. есть реальный ассортимент;
2. есть отдельный поисковый интент;
3. есть уникальный контент;
4. есть реальные товары;
5. есть FAQ/характеристики;
6. есть CTA;
7. страница коммерчески значима.

Остальные комбинации:
- не индексировать;
- canonical на родителя или использовать согласованный noindex/служебный механизм;
- не включать в sitemap.

Не создавать SEO-фабрику из тысяч одинаковых комбинаций.

# 24. Главная архитектурная идея

Сайт должен быть не «онлайн-витриной», а **B2B digital sales platform**:

```text
ПОИСК / РЕКЛАМА / DIRECT
          ↓
        САЙТ
          ↓
┌─────────┼──────────┬────────────┐
│         │          │            │
Модель   Параметры   ТЗ          Аналог
│         │          │            │
Product  Selection  Upload       Form
└─────────┴──────────┴────────────┘
          ↓
      Квалификация
          ↓
          CRM
          ↓
        Инженер
          ↓
  Техническое решение
          ↓
           КП
          ↓
         Сделка
```

**Ключевой принцип:** не продавать пользователю каталог; помочь ему быстро получить корректное техническое решение и передать квалифицированную заявку в продажи.
