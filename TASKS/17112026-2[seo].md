# Техническое задание на внедрение SEO-оптимизации сайта HubeiEnergy.ru

**Исполнителям (Вебмастеру / Контент-менеджеру / Разработчику):**
Данный документ содержит готовые данные и структуры для внедрения на сайт https://hubeienergy.ru/. Все работы направлены на улучшение видимости сайта в Яндексе и Google в B2B-сегменте.

---

## БЛОК 1. Аналитика и Техническое SEO (Для Вебмастера / Программиста)

### 1.1 Настройка Яндекс Метрики и Вебмастера
1. Проверить корректность установки счетчика Яндекс Метрики в `<head>` всех страниц.
2. В Яндекс Метрике настроить следующие **JavaScript-события (Цели)**, критически важные для B2B:
   * **Клик по email:** отслеживание кликов по ссылкам `mailto:`.
   * **Скачивание опросного листа/каталога:** отслеживание кликов по ссылкам, содержащим `.pdf`, `.doc`, `.xlsx`.
   * **Отправка формы:** успешная отправка формы «Получить КП» или «Заказать звонок».
3. В Яндекс Вебмастере: привязать счетчик Метрики (Настройки -> Привязка к Яндекс.Метрике).

### 1.2 Файл robots.txt и sitemap.xml
Разместить в корне сайта файл `robots.txt` следующего содержания (замените URL карты сайта на актуальный):
```text
User-agent: *
Disallow: /admin/
Disallow: /bitrix/ # Если используется 1С-Битрикс
Disallow: /wp-admin/ # Если используется WordPress
Disallow: /search/
Disallow: /*?* # Закрываем параметры фильтров, кроме пагинации
Disallow: /*&uid=
Allow: /wp-admin/admin-ajax.php

User-agent: Yandex
Disallow: /admin/
Disallow: /search/
Disallow: /*?*
Clean-param: utm_source&utm_medium&utm_campaign

Sitemap: https://hubeienergy.ru/sitemap.xml
```
**Требования к sitemap.xml:** Должен обновляться автоматически при добавлении новых товаров/страниц. Должен содержать только страницы с кодом ответа 200.

### 1.3 Чек-лист технических правок (Устранить фатальные ошибки)
- [ ] **Микроразметка:** Внедрить `Schema.org/Product` на карточки трансформаторов и `Schema.org/Organization` на страницу контактов.
- [ ] **Дубли страниц:** Настроить 301 редирект с `www` на `без-www`, а также со страниц со слэшем на конце (`/`) на без слэша (или наоборот, выбрать единый стандарт).
- [ ] **Скорость (Core Web Vitals):** Оптимизировать изображения (перевести в формат WebP).
- [ ] **Адаптивность:** Убедиться, что таблицы с характеристиками скроллятся по горизонтали на мобильных устройствах.
- [ ] **SSL-сертификат:** Проверить, что нет смешанного контента (Mixed Content), все скрипты и картинки загружаются по `https://`.

## БЛОК 3. Коммерческие факторы: Проектирование страниц (Для Дизайнера и Верстальщика)

### 3.1 Идеальная карточка товара B2B (Трансформатор ТСЛ 1000/10)
Скомпоновать страницу по следующим блокам:
1. **Фотогалерея:** 3-4 фото трансформатора (желательно реальные фото с завода) + 1 чертеж с габаритами.
2. **Шапка товара:** H1 Заголовок, Артикул, Наличие (На заказ, 30-45 дней).
3. **Блок цены:** Вместо точной цены — надпись «Цена зависит от комплектации и курса валют. Базис поставки: FCA Маньчжурия».
4. **Кнопка (CTA):** Большая кнопка `[Запросить коммерческое предложение]`.
5. **Файлы для скачивания:** Кнопки «Скачать PDF чертеж», «Скачать опросный лист (Word)».
6. **Таблица характеристик (обязательные поля):** 
   - Номинальная мощность (кВА)
   - Номинальное напряжение ВН/НН (кВ)
   - Схема и группа соединения обмоток
   - Потери холостого хода (Вт)
   - Потери короткого замыкания (Вт)
   - Габариты (ДхШхВ) и Масса (кг)

### 3.2 Страница «Доставка и таможня»
Создать информационную страницу. Обязательные блоки:
* Понятная инфографика пути товара: `Завод в Китае -> Склад FCA Маньчжурия -> Таможенная очистка -> Доставка по РФ`.
* Список предоставляемых документов: ГТД (Грузовая таможенная декларация), сертификаты ГОСТ Р / EAC, закрывающие бухгалтерские документы РФ.

## БЛОК 5. Поведенческие факторы и Контент-план (Для Маркетолога)

1. **Интерактив на сайте (Поведенческие факторы):** Разработчику внедрить на сайт простую форму-квиз (калькулятор подбора) из 4 шагов: `Тип (Сухой/Масляный) -> Напряжение -> Мощность -> Email для отправки КП`. Это увеличит время нахождения на сайте (важно для Яндекса).
2. **План статей для раздела "Статьи/Блог" на ближайшие 2 месяца (Писать экспертно, с формулами и схемами):**
   * Расчет потерь в силовых трансформаторах: холостой ход и короткое замыкание.
   * Как правильно заполнить опросный лист на сухой трансформатор ТСЛ.
   * Особенности логистики негабаритных трансформаторов из Китая (FCA Маньчжурия) в 2024 году.
   * Сравнение литой изоляции из эпоксидной смолы и воздушно-барьерной: что выбрать?
3. **Внешние ссылки (Linkbuilding):** Зарегистрировать карточку компании в `Яндекс.Бизнес`, заполнить прайс-лист. Разместить профиль компании в B2B-каталогах: `b2b-center.ru`, `elec.ru`, `supl.biz`.
