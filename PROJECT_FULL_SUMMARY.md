## 1. Общие сведения и технологический стек

Платформа представляет собой современный веб-комплекс для B2B-клиентов (промышленные заводы, проектные институты, генподрядчики подстанций, сетевые компании), совмещающий корпоративный каталог электрооборудования, систему сбора заявок по ТЗ, контентный SEO-хаб и инженерную параметрическую САПР-систему онлайн-расчета силовых трансформаторов с генерацией чертежей по стандартам ЕСКД (ГОСТ 2.301, ГОСТ 2.104).

### Технологический фундамент:
- **Core:** React 18.3.1, TypeScript 5.7.3, Vite 6.2.0.
- **Styling & UI:** Tailwind CSS 3.4.17, PostCSS, Lucide React (иконки), Clsx, Tailwind Merge.
- **Инженерная графика и экспорт:** Векторный SVG CAD-движок, параметрический генератор DXF (AutoCAD / nanoCAD R12/2000), генератор чертежных PDF листов А4 (`jspdf`).
- **Сборка и SEO:** SSG Pre-rendering (`scripts/prerender-ssg.js`), генератор метаданных и семантики (`scripts/generate-seo.js`), микроразметка Schema.org JSON-LD.
- **Аналитика и телеметрия:** Яндекс.Метрика (счетчик `114211100`), SPA-маршрутизация целей `reachGoal`, встроенная CRM-панель управления лидами с вебвизором.
- **CI/CD:** GitHub Actions (`.github/workflows/deploy.yml`) с автоматической сборкой и публикацией в GitHub Pages.

### Этап 6. Инженерная параметрическая САПР-система ЕСКД (19.11.2026, Задание 5)
- **Финальный коммит:** `45d6184` (`feat(cad): add parametric CAD calculator, 2D blueprint engine, and ESKD drafting at /calculator-tr`).
- **Целевой URL:** [https://hubeienergy.ru/calculator-tr](https://hubeienergy.ru/calculator-tr).
- **Масштаб доработки:** Создание полноценного ядра автоматизированного проектирования силовых трансформаторов:

#### 1. Электромагнитный расчетный модуль (`oilTransformerCalculator.ts`, `dryTransformerCalculator.ts`):
- Расчет трансформаторов мощностью от 100 до 63 000 кВА на классы напряжений 6, 10, 20, 35 и 110 кВ.
- Поддержка **нетиповых номиналов мощности** (1850 кВА, 3150 кВА, 7200 кВА, 12500 кВА и любых пользовательских значений).
- Расчет конфигураций обмоток:
  - **Двухобмоточные** (ВН / НН).
  - **Трехобмоточные** с независимым каналом среднего напряжения (ВН / СН / НН).
  - **С расщепленной обмоткой низкого напряжения** (ВН / НН1-НН2) для мощных промышленных и преобразовательных установок с вычислением сквозного сопротивления $u_{k.скв}$ и коэффициента расщепления $K_р$.
- Вычисление фазных токов, токов КЗ, потерь холостого хода $P_0$, нагрузочных потерь $P_k$, напряжения короткого замыкания $u_k\%$ и расчетного КПД при $\cos\varphi = 0.8$.

#### 2. Тепловой солвер и автоматический подбор охлаждения (`thermalSolver.ts`):
- Тепловой баланс по нормативам ПТЭ №343 с проверкой превышения температуры верхних слоев масла ($80\div95^\circ\text{C}$) и обмоток.
- Автоматический расчет требуемой суммарной площади теплоотдачи $S_{\text{охл}}$ (м²).
- Подбор типоразмера панельных радиаторов (высота 1800 мм, ширина 520 мм, межосевое расстояние, количество секций от 12 до 34).
- Автоматический расчет необходимого количества батарей радиаторов.
- Подбор центробежных/осевых вентиляторов принудительного дутья для систем ONAF / AF (расчет расхода воздуха в м³/ч, суммарной электрической мощности двигателей IP55 и автоматики шкафа ШАОТ).

#### 3. Нормативный инспектор ГОСТ и ПУЭ (`normativeRuleEngine.ts`):
- Автоматическая валидация конструкции по ГОСТ Р 52719-2007 (общие ТУ), ГОСТ 20243 (стойкость к токам КЗ), ГОСТ 1516.3 (уровни изоляции и испытательные импульсы грозового перенапряжения LI 1.2/50 мкс), ГОСТ Р 56738-2015 (вводы ВН), ГОСТ Р 55187-2012 (длина пути утечки фарфоровых и полимерных изоляторов) и ПУЭ 7 (маслоприемники, толщина гравийного слоя, противопожарные расстояния).
- Генерация предупреждений и инженерных рекомендаций в случае выхода параметров за пределы допустимых норм.

#### 4. Графический САПР-движок и генератор чертежей ЕСКД (`TransformerBlueprintSvg.tsx`, `dxfGenerator.ts`):
- Построение 3 ортогональных проекций в проекционной связи:
  - **Главный вид (вид спереди):** бак, ребра жесткости, радиаторы, вентиляторы дутья, шкаф управления ШАОТ, вводы ВН/СН/НН, выносной расширительный бак, маслоуказатель, реле Бухгольца, силикагелевый воздухоосушитель, каретки с катками.
  - **Вид сбоку:** глубина бака, компоновка радиаторных блоков, консоли расширителя.
  - **Вид сверху:** расположение крышки, раскладка выводов обмоток, пробки заливки/слива масла.
- Автоматическое пропорциональное масштабирование изделия в стандартную рамку листа формата А4 (297×210 мм) по ГОСТ 2.301.
- Оформление основной надписи (штампа) и спецификации по ГОСТ 2.104 (Форма 1).
- **Экспорт в векторный формат AutoCAD DXF:** генерация файла со строгим разделением по слоям (`TANK`, `RADIATORS`, `FANS`, `BUSHINGS`, `DIMENSIONS`, `TITLE_BLOCK`) с нейтральным именем `gabaritny-chertezh.dxf`.
- **Экспорт в векторный PDF:** прямое сохранение документа высокого разрешения с нейтральным именем `gabaritny-chertezh-a4.pdf`.

#### 5. Коммерческий калькулятор и структура себестоимости (`TransformerCostCard.tsx`):
- Разделение ориентировочной базовой цены на 3 производственные категории: сырье и материалы (электротехническая сталь, медь/алюминий, масло), комплектующие (вводы, РПН/ПБВ, вентиляторы ONAF/AF), заводская сборка и испытания FAT.
- Корректный мультивалютный пересчет в RUB (₽), USD ($) и CNY (¥) с прозрачным форматированием.

#### 6. Дизайн, верстка и визуальная интеграция:
- Баннер перехода в онлайн-расчет в выпадающем меню «Каталог» приведен в соответствие с фирменными цветами сайта (`#072640` / `#0b3d66` / `#e6a417`).
- В Hero-баннер страницы онлайн-расчета гармонично встроена техническая фоновая схема-подложка `Промышленный трансформатор в инженерной схеме.png` с бесшовным градиентным маскированием.
- Сгенерирован статический SSG-снапшот `dist/calculator-tr/index.html` и обновлен `sitemap.xml` с приоритетом 0.95.

## 4. Сценарии быстрого отката (Disaster Recovery)

### Сценарий А. Быстрый откат в существующей рабочей директории
Если требуется отменить последние изменения и вернуть сайт к состоянию коммита `f20c462`:
```bash
# 1. Откатить рабочий каталог к коммиту f20c462
git reset --hard f20c462

# 2. Очистить неотслеживаемые временные файлы
git clean -fd

# 3. Пересобрать проект
npm run build:full

# 4. Принудительно обновить ветку на GitHub (при необходимости)
git push origin main --force
```

### Сценарий Б. Развертывание из Git Bundle в новую папку (без интернета)
```bash
# 1. Перейдите в родительскую директорию
cd D:\_PROMTING\1_SITE

# 2. Клонируйте проект напрямую из бандла
git clone "D:\_PROMTING\1_SITE\19_TR-project\backups\onearth_repo_backup_commit_f20c462.bundle" Onearth_Restored

# 3. Перейдите в созданную папку
cd Onearth_Restored

# 4. Подключите удаленный репозиторий GitHub
git remote set-url origin https://github.com/Andreyleluk-GAS/Onearth.git

# 5. Установите зависимости и запустите сборку
npm install
npm run build:full
```

### Сценарий В. Развертывание из ZIP-архива
Распаковать `onearth_source_backup_commit_f20c462.zip` в целевой каталог, выполнить `npm install` и `npm run build:full`.
